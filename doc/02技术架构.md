# 技术架构

## 架构概述
前后端分离：微信小程序端（uni-app）与管理后台（Vue3 + Vite）通过 HTTP POST接口访问后端。后端统一以 .NET 7 WebAPI 提供服务，采用三层分层（Controller → BLL → DAL），共享领域实体与公用组件；移动端接口（`CNet.App.Api`）与管理后台接口（`CNet.Web.Api`）共用 `CNet.BLL`、`CNet.DAL`、`CNet.Common`、`CNet.Model` 等层，确保业务逻辑与数据访问复用。代码生成器 `CNet.CodeGen` 用于快速生成后台 CRUD 代码与前端页面，减少样板代码。数据库默认 SQL Server（亦提供 MySQL、SQLite 脚本），数据访问以 Dapper/Dapper.Contrib 为主，辅以自定义 DBHelper。接口文档与调试通过 Swagger/Swashbuckle；后台使用 JWT 认证与 Autofac 依赖注入，日志使用 log4net，提供图形验证码与滑块验证码组件。

### 前端
* CNet.UniAPP（移动端）
  - 技术栈：Vue2 + uni-app + uView；支持小程序/H5 多端构建，内置 tabbar 模板与 uView 组件库。
  - 参考地址：uview： https://uviewui.com/components/form.html
* CNet.Web.Admin（管理后台）
  - 技术栈：Vue3 + Vite + TypeScript + Element Plus；使用 Pinia 状态管理、Axios 封装请求、基于 swagger-typescript-api 的接口类型生成；提供多语言、图表、富文本等通用后台能力。
  - 参考地址：Element Plus：https://element-plus.org/zh-CN/component/button.html

### 后端
* 技术栈：.NET 7 WebAPI + Dapper/Dapper.Contrib，Swagger UI；认证采用 JWT Bearer；日志 log4net，验证码 Lazy.SlideCaptcha；代码生成器提供（CNet.CodeGen） Razor 模板与数据库元数据驱动生成。或使用各项目文件下的tt文件生成，如Model实体层可以通过\code\backend\CNet.Model\T4.DapperExt\Main\1Entity.tt生成。

## 技术选型
* 前端
  - 框架与构建：Vue3 + Vite（管理后台）、Vue2 + uni-app（小程序端），TypeScript（后台）。
  - UI/交互：Element Plus、uView；支持 ECharts、富文本（WangEditor）、拖拽布局（SortableJS）。
  - 状态与路由：Pinia、Vue Router；权限基于路由/静态编码表。
  - 工具与工程：Axios/自定义 request 封装、swagger-typescript-api 生成接口类型、ESLint + Prettier、Sass。
* 后端
  - 平台：.NET 7 WebAPI。
  - 数据访问：Dapper/Dapper.Contrib，自定义 DBHelper（SQL Server/ MySQL/ SQLite）。
  - 安全与网关：JWT Bearer 鉴权，支持验证码（滑块/图形）；Swagger/Swashbuckle 提供接口文档。
  - 日志与监控：log4net 本地日志；可扩展为文件/分布式日志。
  - 代码生成：CNet.CodeGen（Razor 模板）自动生成 Controller/BLL/DAL/前端页面。
* 数据库
  - 默认 SQL Server，提供 MySQL、SQLite 初始化脚本；实体层与分页/响应模型统一封装。
